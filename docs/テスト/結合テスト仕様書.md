# 最新型家計簿！「レスマネ」　結合テスト仕様書

本書は[テスト仕様書](テスト仕様書.md)の一部であり、PHPUnit による結合テスト（`tests/Feature/`）の仕様を定義する。

Controller → Service → Repository → DB を通したエンドポイント単位の検証を行う。`RefreshDatabase` トレイトを使用し、マスタデータシーダーを `setUp()` で実行する。
